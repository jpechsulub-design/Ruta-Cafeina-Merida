# Ruta Cafeína Mérida

Sitio web de Ruta Cafeína Mérida: café de altura de Jaltenango, Chiapas, con entrega en Mérida, Yucatán.
Pedidos al 999 259 8155.

Es un sitio estático (HTML, CSS y JavaScript). Para agregar secciones, copia la plantilla comentada al final de `index.html`;
el menú se arma solo con el atributo `data-menu`.
